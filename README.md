The slideshow. Self-contained: CSS, JavaScript, and the site map are all inside the one file.

Viewing it

Open the HTML file in any browser. No build step, no server, no dependencies.

Control	Action
Right arrow, space, or Next	Next slide
Left arrow or Back	Previous slide
Home / End	First / last slide
F or Full screen	Toggle full screen
Read all	Switch to a scrolling single-page view
Swipe	Change slides on a phone
